# 逆ババ抜き

最後まで **ジョーカーを持っていた人が勝ち** のオンライン対戦ババ抜き。ブラウザだけで遊べます。

## 遊び方
- ホストが「部屋を作る」→ 4文字の部屋コード（または招待リンク）を送る
- 参加者はコードを入れて参加。ホストも参加者も、開始前に「プレイヤー」か「観戦」を選べる
- ホストは開始前に NPC を好きな人数だけ追加・削除できる（プレイヤーは人＋NPCで最大18人）
- 1人だけで開始すると、相手はNPC（足りない分は自動で追加）
- 手番の人は次の人の手札から1枚引く。ペアは自動で捨てる。手札がなくなったら脱落（早いほど下位）
- 最後に残った＝ジョーカーを持っている人が優勝

## 通信まわりの仕様
- 試合中に切断 → その席はNPCが代打。同じ端末でページを開き直すと自動で復帰
- 試合中は新しい人は参加不可（試合終了後〜ロビーでは参加可）
- 持ち時間（10〜60秒）を過ぎると自動で1枚引く
- 観戦者に全員の手札を見せるかはホストが設定できる

## Render へのデプロイ
依存パッケージはなし（Node 18 以上の標準機能のみ）。

- New → Web Service → このリポジトリを選択
- Build Command: `npm install`
- Start Command: `npm start`
- Health Check Path: `/healthz`

`render.yaml` も入っているので Blueprint からでも作れます。

## ローカルで動かす
```
npm start
# http://localhost:3000
```
